# 보상 구조 실험 결과

보상을 주는 방식에 따라 Q-learning 에이전트의 탐험 없는 평가 생존일, 종료 원인, 행동 지표가 달라지는지 비교했다. 알고리즘은 Q-learning 하나이고, 환경과 학습 코드는 `docs/experiment-results.md`와 같다. 보상 조건마다 총 보상의 크기가 달라 비교하지 않고, **탐험을 끈 평가의 완료 생존일**을 공통 지표로 썼다.

## 실험 설정

모든 조건에 같은 설정을 썼다. Q-learning, 학습률 0.10, 할인율 0.99, 100,000 에피소드, 학습 시드 0~4, ε은 1.00에서 0.05까지 60,000 에피소드에 걸쳐 선형 감소한다. 1,000 에피소드마다 탐험을 끈 정책을 고정 환경 시드 100개에서 평가했다. 규칙 기반 기준선은 200판 평균 8.73일, 무작위 정책은 1.86일이다.

기본 보상은 step당 +1, 하루 완료 +5, 사망 −20, 무효 행동 −0.5이다.

| 프리셋 | 변경 | 확인하려는 것 |
|---|---|---|
| base | 기본값 | 기준 |
| scale2 | 모든 보상 ×2 | 대조군. base와 같아야 함 |
| step_only | 하루 보너스 0 | 보너스 없이도 같은 전략을 배우는가 |
| day_only | step 보상 0 | 보상이 하루 단위로만 올 때 학습이 느려지는가 |
| bonus20 | 하루 보너스 20 | 밤 대비 행동이 늘어나는가 |
| death0 | 사망 페널티 0 | 페널티 없이도 위험을 피하는가 |
| death100 | 사망 페널티 −100 | 종료 원인이 바뀌는가 |
| invalid0 | 무효 행동 페널티 0 | 학습 속도에 영향을 주는가 |
| grow | step 보상이 일수에 비례해 증가(0.1) | 탐색적 조건 (아래 참고) |

## 조건별 최종 생존일

| 조건 | 최종 평균 생존일 ± 시드 간 표준편차 | 마지막 5회 평가 평균 | 최종 30일 도달률 | 최종 기준선 이상 | 학습 중 기준선 도달 | 최초 도달 중앙값 |
|---|---:|---:|---:|---:|---:|---:|
| base | 9.51 ± 1.02일 | 10.02 ± 0.55일 | 0.6% | 3/5 | 5/5 | 58,000회 |
| scale2 | 9.51 ± 1.02일 | 10.02 ± 0.55일 | 0.6% | 3/5 | 5/5 | 58,000회 |
| step_only | 11.06 ± 1.13일 | 11.48 ± 0.72일 | 5.4% | 5/5 | 5/5 | 55,000회 |
| day_only | 11.76 ± 0.48일 | 11.80 ± 0.42일 | 5.4% | 5/5 | 5/5 | 51,000회 |
| bonus20 | 9.12 ± 0.25일 | 9.10 ± 0.23일 | 2.0% | 5/5 | 5/5 | 66,000회 |
| death0 | 7.84 ± 0.22일 | 7.75 ± 0.32일 | 0.2% | 0/5 | 2/5 | 93,500회 |
| death100 | 10.68 ± 0.75일 | 10.38 ± 0.59일 | 3.4% | 5/5 | 5/5 | 57,000회 |
| invalid0 | 9.86 ± 0.33일 | 9.61 ± 0.61일 | 1.6% | 5/5 | 5/5 | 59,000회 |
| grow | 9.18 ± 0.75일 | 9.07 ± 0.27일 | 1.4% | 4/5 | 5/5 | 67,000회 |

`최종 기준선 이상`은 마지막 평가 시점에 기준선 이상인 시드 수, `학습 중 기준선 도달`은 학습 중 한 번이라도 기준선 이상이었던 시드 수다. 두 값은 다르다. 최초 도달 중앙값은 도달한 시드만으로 계산했다(death0은 2개 시드).

학습 속도는 20,000회와 50,000회 시점의 평가 생존일로도 비교했다.

| bonus20 | 3.76 ± 0.28일 | 7.26 ± 0.36일 |
| death0 | 3.21 ± 0.30일 | 5.92 ± 0.27일 |
| death100 | 4.07 ± 0.26일 | 7.71 ± 0.59일 |
| invalid0 | 3.47 ± 0.08일 | 7.07 ± 0.44일 |

## 학습 후반 종료 원인

학습 후반 10% 구간, 5개 시드 평균이다. 탐험이 포함된 학습 로그이며 평가 정책의 종료 원인이 아니다. 종료 원인은 마지막 step에서 가장 큰 피해를 준 원인이다.

| 조건 | 굶주림 | 기력 고갈 | 몬스터 | 생존 |
|---|---:|---:|---:|---:|
| base, scale2 | 0.35 | 0.02 | 0.62 | 0.01 |
| step_only | 0.34 | 0.04 | 0.61 | 0.02 |
| day_only | 0.38 | 0.04 | 0.56 | 0.02 |
| bonus20 | 0.39 | 0.01 | 0.59 | 0.00 |
| death0 | 0.37 | 0.02 | 0.61 | 0.00 |
| death100 | 0.46 | 0.06 | 0.47 | 0.01 |
| invalid0 | 0.35 | 0.02 | 0.62 | 0.00 |
| grow | 0.38 | 0.02 | 0.60 | 0.00 |

## 결과 해석

차이가 있다는 판정은 최종값과 마지막 5회 평균 모두에서 평균 차이가 두 조건 중 큰 시드 간 표준편차보다 클 때만 했다.

- **scale2**: 5개 시드 모두 평가 결과가 base와 완전히 같았다. 보상 크기만 바꾼 변화는 정책을 바꾸지 않았다.
- **step_only, day_only**: base보다 높았다. 사전 가설(step_only는 비슷, day_only는 느림)은 틀렸다. day_only는 20,000회와 50,000회 평가, 최초 도달 시점도 base보다 앞섰다.
- **bonus20**: base와 구분하지 못했다. 시드 0의 밤 시작 시 쉼터 준비율은 16.3%로 base(16.9%)와 비슷해 "쉼터 준비율이 오른다"는 가설은 지지되지 않았다.
- **death0**: base보다 낮았고 최종 시점에 기준선을 넘은 시드가 없었다. 무작위 정책보다는 크게 높았다.
- **death100**: 생존일은 base와 구분하지 못했다. 종료 원인은 몬스터 0.62에서 0.47로, 굶주림 0.35에서 0.46으로 바뀌었고, 차이가 시드 간 표준편차(0.01~0.02)보다 컸다.
- **invalid0**: 최종 생존일은 base와 구분하지 못했다. 20,000회와 50,000회 평가는 base보다 낮아 학습 중간 속도는 느렸다. 시드 0의 후반 무효 행동 비율은 12.3%로 base(6.1%)보다 높았다.
- **grow**: base와 구분하지 못했다. 보상이 일수에 의존하지만 Q-table 상태에 일수가 없어 에이전트가 일수를 볼 수 없다. 이 결과는 "일수를 모르는 에이전트" 기준이며 증가형 보상의 효과로 결론짓지 않는다.

사후 관찰(사전 가설이 아니며 검증하지 않았다): 하루에 받는 양의 보상 대비 사망 페널티의 비가 클수록 생존일이 대체로 높았다. death0(비 0) 7.84일, bonus20(약 0.8) 9.12일, base(약 1.8) 9.51일, step_only(약 3.3) 11.06일, day_only(4) 11.76일 순이었고, 비가 가장 큰 death100(약 9)은 10.68일이었다.

## 행동 변화 (Q-learning 시드 0)

탐험이 포함된 학습 로그에서 첫 10%와 마지막 10% 구간을 비교했다. 시드 0 하나의 값이므로 시드 전체로 일반화하지 않는다.

| 조건 | 무효 행동 비율 | 6스텝당 식사 횟수 | 식사 직전 평균 포만도 | 밤 시작 시 쉼터 준비율 |
|---|---:|---:|---:|---:|
| base | 20.9% → 6.1% | 0.703 → 0.982 | 3.38 → 2.30 | 24.5% → 16.9% |
| step_only | 20.5% → 4.7% | 0.704 → 1.023 | 3.39 → 2.38 | 24.4% → 19.8% |
| day_only | 20.4% → 4.9% | 0.711 → 0.990 | 3.37 → 2.27 | 24.7% → 35.4% |
| bonus20 | 20.9% → 9.0% | 0.705 → 0.971 | 3.38 → 2.27 | 24.7% → 16.3% |
| death0 | 20.7% → 6.2% | 0.700 → 0.959 | 3.42 → 2.41 | 24.5% → 9.6% |
| death100 | 20.7% → 5.6% | 0.709 → 0.957 | 3.39 → 2.28 | 24.7% → 31.7% |
| invalid0 | 22.0% → 12.3% | 0.704 → 0.969 | 3.39 → 2.24 | 24.9% → 19.2% |
| grow | 20.8% → 7.1% | 0.706 → 0.963 | 3.37 → 2.26 | 24.8% → 29.0% |

보상 변화와 행동 변화가 함께 관찰됐지만 인과를 측정한 것은 아니다. 쉼터 준비율은 밤이 시작되는 순간의 쉼터만 세며, 하루당 식사 횟수는 총 스텝 ÷ 6을 분모로 쓴다.

## 해석 범위

- Q-learning 한 알고리즘, 학습률 0.10의 결과다. SARSA나 Monte Carlo, 다른 학습률(예: 0.20)에서 같은 순서가 나오는지는 확인하지 않았다.
- 시드 5개이므로 경향으로 읽어야 한다. 학습량은 에피소드 수로 맞췄고, 오래 사는 정책은 같은 에피소드에서 더 많은 환경 스텝을 경험한다.
- 30일 도달률은 모든 조건에서 낮아(최대 5.4%) 조건 간 비교가 어렵다.
- 환경 파라미터는 임의로 정한 값이라 이 환경에서의 결과다.

## 재현 명령

프로젝트 루트에서 가상환경을 활성화한 뒤 실행한다.

```sh
python -m scripts.run_reward_study --workers 2
python -m scripts.run_reward_study --only grow --name grow_only
python -m scripts.run_reward_study --only base scale2 step_only day_only bonus20 death0 death100 invalid0 grow --skip_train
python -m scripts.analyze --tag rw_base_s0 --algo qlearning
```

비교 표와 그래프는 `results/reward_study/reward_compare_table.csv`, `reward_compare_curve.png`에 저장된다. 조건별 행동 분석은 `rw_<프리셋>_s0` 태그(예: `rw_day_only_s0`)로 실행한다. 이 결과는 `compare_rewards.py`에 마지막 5회 평균, 30일 도달률, 기준선 도달 시드 수 열을 추가한 버전으로 만들었다.
