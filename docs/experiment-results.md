# 강화학습 생존 실험 결과

마인크래프트에서 영감을 받은 생존 시뮬레이터에서 에이전트는 식사, 휴식, 사냥·채집, 목재 수집, 쉼터 건설을 선택하며 최대한 오래 살아남도록 학습한다. 실험에는 커밋 `6adbb1c`의 환경과 학습 코드를 사용했다.

## 기본 설정에서의 알고리즘 비교

각 알고리즘을 시드 0~4에서 100,000 에피소드씩 학습했다. 기본 보상과 30일 상한을 사용했고, 1,000 에피소드마다 탐험을 끈 정책을 고정 환경 시드 100개에서 평가했다. 기본 비교 스크립트의 규칙 기반 기준선은 200판 평균 8.735일이다.

| 알고리즘 | 최종 평균 생존일 ± 시드 간 표준편차 | 학습 중 기준선 도달 | 최초 도달 중앙값 |
|---|---:|---:|---:|
| Monte Carlo | 9.94 ± 0.35일 | 5/5 | 46,000회 |
| Q-learning | 9.51 ± 1.02일 | 5/5 | 58,000회 |
| SARSA | 7.05 ± 0.50일 | 0/5 | 해당 없음 |

Monte Carlo는 이번 설정에서 기준선에 가장 일찍 도달했고 최종 평균 생존일도 가장 높았다. `5/5`는 학습 중 한 번 이상 기준선에 도달한 시드 수다. 학습 속도는 에피소드 수 기준으로 비교했다.

## Q-learning 학습률 비교

다른 조건을 고정하고 학습률만 0.05, 0.10, 0.20으로 바꿔 각 5개 시드에서 비교했다.

| 학습률 | 최종 평균 생존일 ± 시드 간 표준편차 | 최종 30일 도달률 | 최종 기준선 도달 |
|---|---:|---:|---:|
| 0.05 | 6.67 ± 0.25일 | 0.2% | 0/5 |
| 0.10 | 9.51 ± 1.02일 | 0.6% | 3/5 |
| 0.20 | 12.84 ± 0.80일 | 7.6% | 5/5 |

시험한 범위에서는 0.20의 최종 생존일이 가장 높았다. 같은 시드끼리 비교하면 다섯 시드 모두 기본값 0.10보다 개선됐으며, 평균 증가 폭은 3.33일이었다.

## Q-learning 시드 0의 행동 변화

탐험을 끈 평가의 평균 생존일은 학습 전 1.91일, 96,000회 시점에 최고 10.37일, 100,000회 최종 시점에 8.41일이었다.

| 학습 로그 지표 | 첫 10% | 마지막 10% |
|---|---:|---:|
| 무효 행동 비율 | 20.9% | 6.1% |
| 6스텝당 식사 횟수 | 0.703회 | 0.982회 |
| 식사 직전 평균 포만도 | 3.383 | 2.303 |
| 밤 시작 시 쉼터 준비율 | 24.5% | 16.9% |

학습 후반에는 무효 행동이 줄고 더 낮은 포만도에서 식사하는 경향이 관찰됐다. 행동 표는 탐험을 포함한 학습 로그이므로, 개별 행동 변화가 평가 생존일을 얼마나 늘렸는지는 이 실험에서 확인하지 않았다.

## 재현 명령

프로젝트 루트에서 가상환경을 활성화한 뒤 실행한다.

```sh
python -m scripts.run_seeds --tag presentation --algos qlearning sarsa mc --seeds 0 1 2 3 4 --episodes 100000 --workers 3
python -m scripts.compare --tag presentation --multi
python -m scripts.analyze --tag presentation_s0 --algo qlearning
python -m scripts.run_seeds --tag alpha005 --algos qlearning --seeds 0 1 2 3 4 --episodes 100000 --workers 2 --alpha 0.05
python -m scripts.run_seeds --tag alpha010 --algos qlearning --seeds 0 1 2 3 4 --episodes 100000 --workers 2 --alpha 0.10
python -m scripts.run_seeds --tag alpha020 --algos qlearning --seeds 0 1 2 3 4 --episodes 100000 --workers 2 --alpha 0.20
```

알고리즘 비교 결과는 `results/presentation_summary/`에 저장된다. 학습률별 결과는 각 시드 폴더의 `qlearning_eval.csv`에서 확인할 수 있다.
